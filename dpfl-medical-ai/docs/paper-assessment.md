# PrivBreast-FL 硕士论文评估与代码对齐

## 论文实际内容

原论文使用 3 个 Kaggle 乳腺癌表格数据集，构造 3 个客户端，使用 DNN、FedAvg 和 Laplace 噪声，并与 Random Forest、SVM、Decision Tree、XGBoost、LightGBM 对比。论文报告三个数据集的高分类精度，并展示了客户端/聚合训练曲线。

## 主要优点

- 研究问题有现实价值，将医疗预测、FL 和 DP 放在同一实验管线。
- 包含多数据集、多个传统基线和较完整的工程过程。
- 论文展示了数据处理、训练动态、分类指标和 ROC，作为硕士项目覆盖面较广。

## 主要问题（按严重性）

### 1. DP 保证未严格成立

论文一处写 Laplace 机制，另一处列出 `epsilon=0.1, delta=1e-5`。经典 Laplace 机制对应纯 $ε$-DP，$δ$ 的引入需要另外的机制/分析。更重要的是：论文代码片段对聚合后参数加噪，但没有定义相邻数据集、证明裁剪后敏感度，也没有轮次组合会计。因此只能说“实现了加噪 FL 原型”，不能据此声称完整形式化 DP 保证。

### 2. 攻击防护声明超出证据

“防止成员推断、属性推断和投毒攻击”没有相应的攻击实验。DP 本身也不自动防御投毒。该声明应删除或改为未来威胁评估。

### 3. 数据泄漏与外部有效性不清晰

文中顺序描述为 SMOTEENN 后再分训练/验证集，如实际代码也如此，则存在合成样本泄漏。三个 Kaggle 数据集作为“三家医院”是模拟，不等于多中心临床验证。高达 100% 的结果需要严格的去重、独立测试与特征泄漏审计。

### 4. 对比不能分离 FL 和 DP 的贡献

缺少严格的 Local-only、Centralized、FedAvg without DP、DP-FedAvg 四方对照，因此无法判断改善来自模型架构、数据处理、联邦协作还是噪声。

### 5. 写作与呈现

原稿存在“joint learning/federated learning”术语混用、重复句、引用标号异常和图表解读超出证据。视觉上基本可读，但部分图表使用截断坐标轴，容易放大差异。

## 与公开代码的对齐

| 论文 | 当前 `dpfl-medical-ai` | 判断 |
|---|---|---|
| 3 个 Kaggle 数据集 | sklearn Wisconsin 单数据集 | 新的简化可复现实现 |
| DNN | 逻辑回归 | 不复现原模型 |
| 聚合后加噪片段 | 每客户端更新裁剪+加噪 | 公开实现的边界更清晰 |
| 动态隐私参数 | 固定每轮 $ε$ | 未实现动态调度 |
| 历史高精度 | 新 smoke 实验 | 不得相互归因 |

## 建议

原文适合作为学位阶段成果和研究起点。如转投论文，建议不做语言小修，而是用当前公开代码为基础重建数据管线、DP 定义/会计、四方消融和攻击评估。
